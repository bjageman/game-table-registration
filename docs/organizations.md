# Organizations

The Settings page has an Organization tab. A signed-in manager with a connected Discord server and channel can create an organization. Names are unique regardless of letter case. The organization uses the creator's selected server and channel for its events.

The creator is an Admin and can search for signed-in users, add them, and set their role. User can view events, Editor can view and change events, and Admin can also manage membership. The creator's role cannot be changed. Members can leave; only the creator can delete the organization.

Each account can select one organization or Personal events. Events created while an organization is selected belong to that organization and are visible only to its members. Personal events are visible only to their creator. Switching selection changes the event list; it does not move existing events. Deleting an organization preserves its events as personal events for their individual creators.
